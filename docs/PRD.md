## 1. 产品概述

### 1.1 一句话定位

帮用户用 **1–3 分钟** 看懂一个全球热点事件的来龙去脉。

### 1.2 产品愿景

做一个「热点事件的历史记录器」，不是单纯新闻流。用户看到的不是零散报道，而是一个事件从爆发、发酵、反转、处置到后续影响的 **结构化时间线**。

### 1.3 核心价值

| 价值点 | 说明 |
|--------|------|
| 脉络清晰 | 把多源新闻聚合成单一事件档案 |
| 可追溯 | 每个关键节点可追溯到原始信源 |
| 持续更新 | 发展中事件自动合并后续报道 |
| 全球视野 | 覆盖多语言、多地区热点 |

### 1.4 非目标（MVP 不做）

- 社交评论区、用户投稿
- 新闻全文存储与展示
- 复杂知识图谱编辑
- 强实时推送（仅基础订阅）
- 专业研究报告导出
- 完整多语言人工编辑后台

## 2. 目标用户

### 2.1 主要用户画像

**「好奇的读者」**

- 年龄：18–45 岁
- 特征：关注时事，但没时间追大量新闻
- 痛点：看到热搜/标题，不知道前因后果
- 期望：快速了解事件背景、当前进展、各方说法

**「事件追踪者」**

- 特征：对特定领域（国际冲突、灾害、科技、财经）有持续关注
- 痛点：信息分散在多个媒体，难以形成连续叙事
- 期望：订阅事件，收到后续关键进展

### 2.2 用户分层

| 层级 | 用户 | MVP 优先级 |
|------|------|-----------|
| P0 | 普通读者 — 浏览热点、看时间线 | 必须满足 |
| P1 | 搜索用户 — 按关键词/地区查找 | 必须满足 |
| P2 | 订阅用户 — 关注事件后续 | 基础能力 |
| P3 | 研究/媒体人员 | 后续版本 |

## 4. 功能范围

### 4.1 MVP 功能清单

#### 4.1.1 首页

- 今日热点事件列表（按热度排序）
- 「刚刚更新」事件流
- 分类快捷入口：政治、灾害、科技、财经、战争、公共安全
- 全球热点地图入口（P1）

#### 4.1.2 热点榜

- 按全球 / 国家 / 分类 / 时间排序
- 显示：标题、一句话摘要、热度、地点、更新时间、来源数量

#### 4.1.3 事件详情页

- 事件标题 + 一句话摘要（≤ 3 行）
- 当前状态标签：发展中 / 已平息 / 长期影响中 / 存疑
- 关键时间线（按时间倒序或正序可切换）
- 主要信源列表（标题 + 媒体 + 发布时间 + 外链）
- 地点、分类、标签
- 相关事件推荐
- 免责声明：「信息来源于公开报道，可能随事态发展变化」

#### 4.1.4 搜索

- 关键词搜索（事件标题、摘要、标签）
- 筛选：地区、分类、时间范围
- 搜索结果按相关度 + 热度排序

#### 4.1.5 订阅（基础）

- 登录用户可订阅事件
- 事件有新时间线节点时生成通知记录
- MVP 阶段：站内通知列表，不做 App Push

#### 4.1.6 后台数据管道（无 UI）

- 定时采集 GDELT DOC API + RSS
- 新闻去重与标准化
- 事件聚类
- AI 摘要与时间线生成
- 热度计算与排序

## 5. 交互与体验要求

### 5.1 阅读体验

- 事件详情顶部先给结论，再展开时间线
- 时间线节点用短句（≤ 50 字），不做长篇复述
- 每个节点必须关联 ≥ 1 个来源
- 发展中事件顶部显示黄色提示条

### 5.2 视觉风格

- 简洁、新闻阅读感，避免「数据库感」
- 时间线为主视觉元素
- 地图作为发现入口，非核心阅读路径
- 支持浅色/深色模式（P1）

### 5.3 性能要求

| 指标 | 目标 |
|------|------|
| 首页首屏 | < 2s（4G 网络） |
| 事件详情 | < 1.5s |
| 搜索响应 | < 1s |
| 数据刷新 | 每 15–30 分钟 |

## 6. 内容与安全策略

### 6.1 版权

- **不存储、不展示新闻全文**
- 仅保存：标题、摘要（≤ 300 字）、URL、来源、发布时间
- 用户点击后跳转原文

### 6.2 事实准确性

- AI 生成摘要必须标注「自动摘要」
- 每个时间线节点关联原始来源
- 来源数量 < 3 的事件标记为「低置信度」
- 存在明显矛盾报道时标记「存疑」

### 6.3 合规

- 敏感政治内容：展示来源，不做立场判断
- 地区合规：根据运营地区配置内容过滤规则
- 用户协议与免责声明必须包含

### 6.4 多语言

- MVP：中文界面 + 英文/多语新闻自动翻译摘要
- 原文链接保留原始语言

## 7. 验收标准

| # | 验收项 | 标准 |
|---|--------|------|
| AC-01 | 热点列表 | 用户能看到最近 24 小时全球热点事件列表 |
| AC-02 | 多源覆盖 | 每个热点事件展示 ≥ 3 个独立来源 |
| AC-03 | 事件详情 | 包含摘要、时间线、来源链接、更新时间 |
| AC-04 | 搜索 | 支持关键词 + 地区 + 分类搜索 |
| AC-05 | 事件合并 | 同一事件后续报道自动合并到已有事件 |
| AC-06 | 持续更新 | 发展中事件在 30 分钟内有新报道时能更新 |
| AC-07 | 时间线 | 每个事件 ≥ 3 个时间线节点（有充足来源时） |
| AC-08 | 外链 | 所有来源链接可点击跳转原文 |
| AC-09 | 免责声明 | 事件详情页展示信息来源与免责声明 |
| AC-10 | 响应式 | Web 在手机浏览器上可正常浏览 |
